# AuditIQ v10

منصة دراسة ومراجعة احترافية لـ **ACCA DipIFR** والمراجعة المالية — يوسف صلاح.

تطبيق ويب من ملف واحد (Single-file HTML/CSS/JS) — بدون أي frameworks.

## المميزات
- 🎯 دليل امتحان DipIFR يونيو 2027 (تاريخ قابل للتعديل + المعايير الداخلة) · واجهة Focus Hub جديدة
- 📊 محلل النسب المالية + رسوم بيانية مقارنة بالقطاع (ISA 520)
- 🧠 مخطط مذاكرة ذكي + Spaced Repetition (SM-2)
- 🃏 Flashcards · كويزات · امتحانات تجريبية
- 🔎 أدوات مراجعة: Going Concern · Subsequent Events · Related Parties · Group Audit
- 🏦 حاسبة IFRS 9 ECL · DuPont · Altman · Beneish
- 🏛️ أدوات ضريبية مصرية · 🌙 وضع ليلي · 💾 نسخ احتياطي · 📲 PWA (يعمل offline)

## التشغيل
